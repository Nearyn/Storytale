# Themes

Choose a theme in **Esc → Options → AddOns → Storytale**; click a tile to apply it.

Every theme except Frameless and Cinematic is shown **as a bubble** by default: the NPC's line in a bubble above them, and with **Also dress the choice wheel**, each choice in a small matching bubble. Uncheck **Show themes as bubbles** to get the **frame** version instead. Azeroth Bubble, Illuminated Bubble and Whisper are always bubbles.

> *Illustration* images are drawn from the addon's own textures and colours on an in-game screenshot; the font may differ slightly in game.

## Notes

- **Books and letters** are never shown in a bubble: they use a page (Gilded Vellum if a bubble theme is chosen).
- **Experimental** themes are new and have had little testing in game. Feedback is welcome in the [issues](https://github.com/Nearyn/Storytale/issues).
- The two **DialogueUI** themes use art from the DialogueUI addon by its author.

# Thèmes (français)

Choisissez un thème dans **Échap → Options → AddOns → Storytale** ; cliquez sur une vignette pour l'appliquer.

Tous les thèmes sauf Sans cadre et Cinématique s'affichent **en bulle** par défaut : la réplique du PNJ dans une bulle au-dessus de lui et, avec **Habiller aussi la roue des choix**, chaque choix dans une petite bulle assortie. Décochez **Afficher les thèmes en bulle** pour avoir la version **en cadre**. Bulle d'Azeroth, Bulle enluminée et Murmure restent toujours en bulle.

> Les images *illustration* sont dessinées à partir des textures et couleurs de l'addon, sur une capture du jeu ; la police peut légèrement différer en jeu.
